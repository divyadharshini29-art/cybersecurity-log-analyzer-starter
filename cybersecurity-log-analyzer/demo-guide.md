# Demo Walkthrough Script

Target length: 2–4 minutes. Record your actual screen after you have run and tested the application.

1. Introduce the project as an educational cybersecurity log analyzer.
2. Show the dashboard with the built-in synthetic sample.
3. Explain the total event, failed login, and successful login metrics.
4. Change the failed-login threshold and show how flagged IPs change.
5. Upload `sample_logs.txt` and show the parsed event table.
6. Download the CSV export.
7. Explain the investigation recommendations and why alerts need context.
8. Show the README, security architecture, and testing report.
9. Close by describing limitations and planned improvements.

Do not claim that the app detected a real attack. The included data is synthetic.
